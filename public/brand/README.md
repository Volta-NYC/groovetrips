# GrooveTrips logo

`groovetrips-logo.png` is the original, unmodified logo used in the header of
https://www.groovetrips.com/, retrieved on October 14, 2026.

Source: https://images.squarespace-cdn.com/content/v1/6924ca09a30eb459ab5a3e05/24edd601-1741-4c4d-b068-338484a3a833/logo+bg+groovetrips+%282%29.png?format=1500w

The client approved using this asset while the full brand kit is unavailable.
The shared `BrandLogo` component preserves the artwork and color; CSS places
the transparent image padding outside the visible logo frame. The same source
asset is used for the browser icon.
